# Vintage Photo Booth
A browser-based photo booth for laptop, tablet, and phone.

Features:
- Camera preview
- 4-photo session with countdown
- Vintage / Pinterest / Film / Polaroid templates
- Custom frame color and text
- 4-photo strip or 2x2 layout
- Save JPG
- Print through the browser print dialog

Important: browsers do not normally allow a website to silently print without a print dialog. For true one-tap automatic printing to a connected printer, use a kiosk/native printing bridge later.

For GitHub Pages, open Settings > Pages and deploy from `main` / `(root)`.
