MY PHOTOBOOTH — iPhone 11 first version

Included:
- iPhone/Safari camera access
- Front-camera preview
- 3-second countdown
- 4 automatic photos
- 2x2 photo layout
- Simple branding
- Retake
- Save/share final JPG
- PWA manifest

IMPORTANT:
Safari camera access normally requires HTTPS (or localhost). The easiest free way to test this on an iPhone is to upload the folder to a static HTTPS host such as GitHub Pages, Netlify, or Cloudflare Pages.

How to use:
1. Put index.html and manifest.json in the same web folder.
2. Publish the folder using any HTTPS static hosting service.
3. Open the HTTPS link in Safari on your iPhone 11.
4. Allow camera access.
5. Tap START PHOTOBOOTH.
6. After four photos, tap SAVE PHOTO.
7. To make it feel like an app: Safari > Share > Add to Home Screen.
